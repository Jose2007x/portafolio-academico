PORTAFOLIO ACADÉMICO — JOSÉ LUIS
================================
Proyecto de aprendizaje de Introducción a los Lenguajes de Internet.

ARCHIVOS
- index.html: estructura de la página, metadatos, títulos, secciones y enlaces.
- styles.css: colores, tipografías, diseño adaptable y estilos visuales.
- script.js: menú móvil, año del pie de página y botón para copiar presentación.
- README.txt: instrucciones del proyecto.

USO LOCAL
1. Descomprime el archivo ZIP.
2. Abre index.html en Chrome, Edge o Firefox.
3. Recorre las secciones, prueba el menú móvil y el botón «Copiar presentación».
La página funciona sin servidor. La fuente visual intenta cargar Google Fonts si hay conexión; sin Internet utiliza Arial.

PUBLICACIÓN MEDIANTE GITHUB PAGES
1. Accede a GitHub y crea un repositorio público llamado portafolio-academico.
2. Sube index.html, styles.css, script.js y README.txt a la RAÍZ del repositorio (no la carpeta contenedora).
3. En Settings > Pages, selecciona Deploy from a branch.
4. Branch: main; carpeta: /(root). Pulsa Save.
5. Comprueba la URL que GitHub muestra en Settings > Pages y añádela a la entrega.
AVISO: Esta publicación NO se ha realizado automáticamente. Requiere tu cuenta.

PRIVACIDAD
Antes de publicar revisa el contenido. No agregues teléfono, dirección física,
identificaciones, cumpleaños, fotos privadas ni correos personales sin decidirlo tú.
El contenido es académico y algunas descripciones son resúmenes de proyectos.
